# 小智桌面宠物 PRD (v1.0 构想版)

**目标硬件:** ESP32-S3-N16R8 (16MB Flash, 8MB PSRAM)
**基础架构:** 基于小智 AI 聊天机器人的流式语音交互体系与 MCP 协议。
**产品定位:** 具备生命感、陪伴感与桌面实用性的实体桌面 AI 助手。

---

## 1. 增强“生命感”与自主行为 (Tamagotchi 机制)
目标：打破传统语音助手“不唤醒即死亡”的死板状态，赋予宠物主动性和情感状态。

*   **情绪与状态机引擎**
    *   在设备端状态机中引入隐藏数值体系（如：心情、饱食度、精力）。
    *   **数值衰减与恢复**：长时间不互动会导致“饱食度”和“心情”下降；交互频率增加会提升“心情”。
    *   **状态表现**：数值处于低谷时，宠物在 idle 状态会表现出无精打采或打瞌睡（屏幕变暗，播放微弱打呼声）。
*   **主动搭话 (Proactive Engagement)**
    *   结合定时器与本地上下文环境，宠物会主动发起简单对话。
    *   **场景示例**：静默超过 2 小时后，随机发起健康提醒（“主人，你已经工作好久了，喝口水休息一下吧！”）。
*   **Idle 状态微互动**
    *   待机状态下，增加随机的微小动作动画（眨眼、东张西望）。
    *   偶尔发出无意义但可爱的环境音效（如吹口哨、打哈欠、轻哼）。

## 2. 环境感知交互 (Sensors 扩展)
目标：通过低成本传感器让宠物感知物理世界，形成真实的互动反馈。

*   **“抚摸”反馈**
    *   **硬件依赖**：APDS9960 或红外避障/接近传感器（安装在机身顶部）。
    *   **交互表现**：当检测到手掌在顶部悬停或抚摸时，屏幕切换至“享受/眯眼”的表情，并播放开心的音效。
*   **光线感知与自适应**
    *   **硬件依赖**：光敏电阻或环境光传感器。
    *   **交互表现**：关灯导致环境变暗时，宠物自动打哈欠并闭眼进入“睡眠模式”，降低屏幕背光亮度以减少功耗和光污染；开灯时自动“惊醒”。
*   **环境温湿度感知**
    *   **硬件依赖**：AHT20/SHTC3 等温湿度传感器。
    *   **交互表现**：室内温度高于特定阈值（如 30℃）时，主动播放流汗动画并抱怨太热；温度过低时播放发抖动画。

## 3. 边缘视觉与多模态 (Camera 扩展)
目标：利用 S3 的 DVP/SPI 摄像头接口与 8MB PSRAM 进行轻量级视觉处理。

*   **人脸跟随与视线追踪**
    *   基于 ESP-DL 在本地运行轻量级人脸检测模型。
    *   当检测到人脸在视野中移动时，屏幕上的“眼睛”UI 会跟随人脸的坐标位置进行偏转，形成“它在看着我”的错觉。
*   **“看图说话”模式**
    *   设定特定的视觉唤醒键（物理按键或语音触发）。
    *   捕获图像后通过云端 MCP 上传给多模态大模型（如 Qwen-VL, GPT-4o），实现物品识别或视觉问答（例如：“看看我今天穿的衣服好看吗？”）。

## 4. 桌面生产力助手
目标：在娱乐属性之外，提供切实的桌面生产力辅助。

*   **番茄钟与专注模式**
    *   通过语音唤醒（“帮我设定 25 分钟专注模式”）。
    *   屏幕 UI 切换为倒计时与“专注/严肃”的表情。
    *   在专注模式下如果尝试与它闲聊，它会拒绝回复并提醒“专心工作”。
    *   提供白噪音（雨声、海浪声）的本地或流式播放选项。
*   **PC 状态副屏监控**
    *   通过本地网络 (WebSocket/UDP) 或蓝牙 (BLE) 接收来自 PC 端的数据。
    *   宠物屏幕化身为仪表盘，实时显示 PC 的 CPU 温度、内存占用等信息。
*   **消息代收与提醒**
    *   通过蓝牙连接手机。当手机收到重要通知时，宠物通过语音或屏幕弹窗提醒（“主人，收到一条新消息，需要我念给你听吗？”）。

## 5. 音频娱乐拓展
目标：丰富桌面听觉体验。

*   **桌面氛围节拍器**
    *   利用板载麦克风监听环境声音强度。
    *   在检测到连续的音乐节拍时，屏幕表情或外围 RGB 灯带会根据音频频率进行动态可视化（“蹦迪”模式）。
*   **蓝牙音箱模式 (A2DP)**
    *   利用 ESP32-S3 原生的蓝牙音频协议。
    *   支持切换至音箱模式，连接手机作为桌面小音箱使用。

## 6. 物理维度的拓展 (机电联动)
目标：突破纯屏幕交互，增加物理维度的动作反馈。

*   **2-DOF 颈部动作 (Pan/Tilt 舵机控制)**
    *   **硬件依赖**：微型舵机底座 + 麦克风阵列 (DOA 声源定位)。
    *   **交互表现**：当用户从左侧唤醒宠物时，它会在物理层面转头看向左侧；在语音播报或表达强烈情绪时，配合语调进行点头、摇头等动作，极大增强生命感。
